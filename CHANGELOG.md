# Changelog

## 1.7.0 — Initial release

- Added Console FTP with configurable address, port, credentials and remote asset folder.
- Added paired downloads and reviewed uploads with verified local console backups.
- Added stale-file checks, byte-for-byte upload readback and attempted restoration after transfer failure.
- Added About information for SaveEditors and GPL-3.0-only licensing.
- Added matching particle palettes for every theme, with an explicit option to resume automatic matching after custom particle edits.
- Preserved particle colors and matching mode through undo/redo and saved effect presets.
- Included documentation with two console demonstration videos, an editor screenshot and transfer/recovery instructions.

Includes strip color editing, particle palettes, ramp textures, reusable presets,
per-user settings, portable application paths, verified local saves and backup recovery.

Desktop effect previews remain approximate. Console animation timing remains under investigation.
